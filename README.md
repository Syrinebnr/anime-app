# Anime Explorer

Anime Explorer is een moderne anime webapp gemaakt met JavaScript en Vite.

Gebruikers kunnen:
- anime zoeken
- filteren
- sorteren
- favorieten opslaan
- dark/light mode gebruiken

## Features

- Zoekfunctie
- Filter op status
- Sorting op score
- Favorieten systeem
- LocalStorage
- Responsive design
- Dark/Light mode
- Anime API integratie

## Gebruikte technologieën

- HTML
- CSS
- JavaScript
- Vite
- Jikan API

npm install
